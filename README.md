# PGN App

A Python application for working with PGN chess files.

## Development

Create and activate a virtual environment, then install the project in editable mode:

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
py -m pip install --upgrade pip
py -m pip install -e .
```

Run the application:

```powershell
pgn-app
```
